# MeowBot 🤖

> **[🇬🇧 English version](README.md)**

בוט פקודות וואטסאפ מודולרי ודו-לשוני (עברית/אנגלית), בנוי על [Baileys](https://github.com/WhiskeySockets/Baileys).
כל מתג התנהגות — קידומת, שפה, מצב גישה, מודל AI, קולדאון, מערכות פרטיות — נשלט מקובץ `.env`.
שום סוד לא כתוב בקוד; מפתח ה-API יושב ב-`.env` ולא עולה לגיט.

**59 פקודות**: בינה מלאכותית, ניהול קבוצות, ניהול מורשים, משחקים וכלי עזר —
כולל מערכת מוניטין מלאה, הגנת אנטי-לינק, שמירת הודעות שנמחקו, שמירת הודעות חד-פעמיות,
תזכורות, הורדת אודיו מיוטיוב עם תפריט בחירת שיר בלחיצה, וריאקשן אימוג׳י לכל פקודה.

---

## ✨ עיקרי הדברים

- **🌍 דו-לשוני באמת** — כל מחרוזת שהמשתמש רואה קיימת בעברית ובאנגלית (`src/lang/he.js` / `src/lang/en.js`).
  מחליפים עם `BOT_LANG`. שמות פקודות בעברית עובדים גם כשהבוט על אנגלית, ולהפך.
- **🔍 ביקורת עצמית לשפות** — `npm run audit` בודק זהות מפתחות בין השפות ונכשל אם מחרוזת עברית
  אחת דולפת למצב אנגלית. מפתח חסר מוצג כ-`[key]` בולט — אף פעם לא נופל בשקט לשפה השנייה.
- **📋 תפריט יוטיוב בלחיצה** — תוצאות החיפוש מגיעות כרשימת `ListMessage` *קלאסית*
  (דרך [baileys-buttons](https://www.npmjs.com/package/baileys-buttons)), שמוצגת **גם באנדרואיד וגם באייפון**.
  (רשימת `native_flow` אינטראקטיבית *לא* מוצגת באייפון — הבוט נמנע ממנה בכוונה.)
- **🔑 התחברות עם קוד צימוד** — בלי לסרוק QR. הבוט מדפיס קוד, מקלידים אותו פעם אחת בטלפון.
- **🧠 מודל AI מתחלף** — `GEMINI_MODEL` ב-`.env` (כל מזהה מודל של Gemini, בלי לגעת בקוד).
- **🛡️ מערכות פרטיות** — אנטי-מחיקה (מעביר הודעות שנמחקו לבעלים), שמירת חד-פעמי,
  אנטי-לינק עם רשימות שחורה/לבנה ושלושה מצבי אכיפה.
- **⚙️ שליטה פסיכופתית ב-`.env`** — כ-25 מתגים, ראה [תצורה](#-תצורה).

## 🚀 התחלה מהירה

```bash
git clone https://github.com/meowguck-art/meowbot.git
cd meowbot
npm install
cp .env.example .env
# עורכים את .env: BOT_NUMBER, OWNER_NUMBERS, GEMINI_API_KEY, BOT_LANG ...
node index.js
```

בהרצה הראשונה הבוט מדפיס קוד צימוד:

```
[MeowBot] Pairing code for 9725XXXXXXXX: 1234-5678
```

בטלפון: **וואטסאפ ← מכשירים מקושרים ← קישור באמצעות מספר טלפון** ← מקלידים את הקוד.
ההתחברות נשמרת בתיקיית `./auth/` — מצמדים פעם אחת בלבד.

### Termux (אנדרואיד)

```bash
pkg install nodejs ffmpeg
# הבינארי של yt-dlp מתגלה אוטומטית ב-/data/data/com.termux/files/usr/bin/yt-dlp
npm install
node index.js
```

`ffmpeg` נדרש לסטיקרים. `yt-dlp` נדרש להורדות מיוטיוב.

## ⚙️ תצורה

הכל ב-`.env` (ראה `.env.example`):

| משתנה | ברירת מחדל | מה זה עושה |
|---|---|---|
| `BOT_NUMBER` | — | המספר של הבוט עצמו (ספרות). לצימוד בקוד |
| `OWNER_NUMBERS` | — | מספרי בעלים מופרדים בפסיק. עוקפים הרשאות, קולדאון ובדיקות מנהל |
| `PREFIX` | `!` | קידומת הפקודות |
| `BOT_LANG` | `he` | `he` \| `en` — כל תשובה, תפריט ועזרה |
| `BOT_MODE` | `authorized` | `self` (בעלים בלבד) \| `authorized` (בעלים + מורשים) \| `public` (כולם) |
| `GEMINI_API_KEY` | — | מפתח Google AI Studio לפקודות `שאל`/`סכם`/`דמיין` |
| `GEMINI_MODEL` | `gemini-1.5-flash` | כל מזהה מודל של Gemini — מחליפים בלי לגעת בקוד |
| `AI_NAME` | `MeowBot` | שם הבוט בתוך פרומפטי ה-AI |
| `REACTIONS_ENABLED` | `true` | ריאקשן אימוג׳י אחרי כל פקודה (`❌` על שגיאה, `⏱️` על קולדאון) |
| `COOLDOWN_SECONDS` | `5` | קולדאון בין פקודות לאותו משתמש (בעלים פטורים) |
| `WARN_LIMIT` | `3` | אזהרות עד שהרחקה אוטומטית (נשמר ב-DB, שורד ריסטארטים) |
| `ANTI_DELETE` | `true` | העברת הודעות שנמחקו ("מחק לכולם") לבעלים |
| `ANTI_DELETE_MEDIA` | `true` | כולל את המדיה של ההודעה שנמחקה |
| `SAVE_VIEW_ONCE` | `true` | שמירת תמונות/סרטוני חד-פעמי והעברתם לבעלים |
| `ANTILINK_DEFAULT_MODE` | `delete_only` | `delete_only` \| `delete_kick` \| `warn_delete` |
| `YT_DLP_PATH` | אוטומטי | ריק = זיהוי אוטומטי (נתיב Termux, ואז `PATH`) |
| `YT_AUDIO_FORMAT` | `opus` | `opus` (הודעה קולית) \| `mp3` |
| `YT_VOICE_NOTE` | `true` | שליחת הורדות כהודעות קוליות |
| `STICKER_AUTHOR` / `STICKER_PACK` | `MeowBot` | מטא-דאטה של סטיקרים |
| `AUTH_DIR` / `DB_FILE` / `TEMP_DIR` | `./auth` `./data.json` `./temp` | מיקומי אחסון |

### צינור הבקשה

`messages.upsert` ← מחיקה? ← שמירה לבאפר (אנטי-מחיקה) ← אנטי-לינק ← לחיצות בתפריט ←
תשובות טריוויה ← קיצורי `!5` ← פירסור פקודה ← שערי בעלים/מנהל/הרשאה ←
קולדאון ← handler ← ריאקשן אימוג׳י.

## 🌍 מערכת השפות

- `src/lang/he.js` ו-`src/lang/en.js` מכילים **כל** מחרוזת שהמשתמש רואה (267 מפתחות כל אחד).
- `src/lang/aliases.js` מכיל כינויים דו-לשוניים לפקודות משנה (`הפעל`/`on`, `כבה`/`off`, יחידות זמן, …).
- שמות פקודות בעברית נרשמים לצד האנגליים, אז `!עזרה` עובד גם כש-`BOT_LANG=en`.
- `npm run audit` בודק: (1) זהות מפתחות בין השפות, (2) אפס תווי עברית ב-`en.js`,
  (3) אפס תווי עברית בכל מקום אחר חוץ מ-`he.js`, `aliases.js` ושמות פקודות בעברית.
  מפתח חסר מוצג כ-`[the.key]` — לעולם לא נופל בשקט לשפה השנייה.
